 JHS Attendance Management System

A web-based attendance management system designed to help Junior High Schools (JHS) record and manage student attendance digitally.

The project aims to simplify attendance tracking, reduce manual record-keeping, and make student attendance information easier to manage.

Technologies Used

* React, CSS, and JavaScript
* Node.js and Express.js
* PostgreSQL


Project Goal

To provide schools with a simple digital solution for managing student attendance efficiently.
